# Build a GOAT: iOS app (Capacitor 8)

The iOS app wraps the one-file game (`../index.html`, the same file GitHub Pages serves) in a
Capacitor shell. The setup is a copy of The Fort's (`the-fort/native`), which itself mirrors Euchre
Unleashed's: Capacitor 8 with Swift Package Manager plugins, manual signing with the team's one
distribution certificate, fastlane, and TestFlight builds from GitHub Actions (`../CI_SETUP.md`).

- **Bundle id:** `com.buildagoat.game`. It can't change once the app is published. **Home-screen
  name:** Build a GOAT.
- **Devices:** iPhone, portrait only. iPads run the iPhone build.
- **Plugins:** `@capacitor-community/admob` (bottom banner, rewarded ad, ATT, UMP consent),
  `@revenuecat/purchases-capacitor` (gem shop, Remove Ads), `@capacitor/preferences` (native copy
  of the progress keys), `@capacitor/app` (background and foreground), `@capacitor/splash-screen`,
  `@capacitor/haptics`.

## Monetization

| What | Where in the game | Notes |
|---|---|---|
| **Banner ad** | bottom of every screen | Adaptive banner pinned above the home indicator. The dock and page padding move up by its height (`html.adb`, `--adH`). Gone for good once Remove Ads is owned. |
| **Double your rewards** | end-of-career screen, gems card | One rewarded ad per career doubles that career's gems **and** GTP. finish() has already paid once; the ad pays `S.gemsRun` and `S.gtpRun` once more, guarded by `S.dbl`. Never on Rookie or the Daily Build. |
| **Gem Shop** | its own menu item (after Equipment), shown only when the store is on; Equipment and the GTP Store link to it | Five gem packs and Remove Ads, plus **Restore purchases** (App Review requires it). |

| **Gems for GTP** | GTP Store, under the perks | Trade 10/30/75 gems for 20/65/170 GTP (`GEM_TRADES`), about 2 GTP per gem; a career pays ~3.7 GTP per gem earned, so trading never beats playing. Works on the web too. |

On the web (GitHub Pages) the banner, the reward ad and the Gem Shop don't show. Add `?dev=1` to the URL to play every flow with a
simulated `confirm()` sheet and a placeholder banner strip. Under Witness, Plat does nothing.

## How the game talks to the device

```
index.html  Plat (the "PLATFORM (Plat)" section) ──> window.Shell (shell.js) ──> Capacitor plugins
```

`build_www.py` injects `capacitor.js` and `shell.js` into `<head>`, so `window.Shell` exists
before the game's script defines `Plat`. `Plat` never calls a plugin directly. `shell.js` does,
and every call degrades instead of throwing: no ad means `false`, and a failed purchase grants nothing.

| Game side (`Plat`) | Shell | Plugin calls |
|---|---|---|
| `Plat.boot()` at startup | `store.hydrate`, `configure`, `ads.onBanner`, `iap.owned`, `ready` | Preferences, ATT, UMP, rewarded preload, RevenueCat, SplashScreen.hide |
| `Plat.banner()` | `ads.showBanner()` / `ads.removeBanner()` | `showBanner` (ADAPTIVE_BANNER, BOTTOM_CENTER), `resumeBanner`, `removeBanner`; retried with backoff after a failed load |
| `Plat.ad()` | `ads.showRewarded()` → `{ rewarded, reason? }` | `prepareRewardVideoAd` / `showRewardVideoAd`; settles on dismissal |
| `Plat.buy(sku)` | `iap.purchase(id)` → `{ ok, cancelled?, error? }` | `getProducts` + `purchaseStoreProduct` |
| `Plat.restore()` | `iap.restore()` → owned ids | `restorePurchases`, `syncPurchases` as a fallback |
| `Plat.price(sku, usd)` | `iap.price(id)` | the localized `priceString` |
| progress keys | `store.put('bag_all', json)` | `Preferences.set` (debounced; flushed on background) |

**Save durability.** iOS can purge a WKWebView's localStorage. Plat copies every `bag_*` progress
key (gems, gear, GTP, achievements, Hall of Builds, `bag_noads`...) into one JSON blob, `bag_all`,
and mirrors it to Preferences. At launch, `Shell.store.hydrate('bag_all')` puts it back when
localStorage was purged or older. The in-progress run (`bag_run*`, `bag_build`) is not mirrored:
it can be large, and losing it is rare and recoverable.

**ATT at launch**, before any ad loads (AppDelegate also asks once the app is active). Ads are
non-personalized unless ATT is authorized and UMP consent is obtained or not required.

## Layout

```
shell.js            window.Shell over the plugins; plain ES5, no bundler
build_www.py        ../index.html + capacitor.js + shell.js + fonts/ + music/ -> www/ (build stamp, id checks)
www/                generated by build_www.py (gitignored; never edit)
fonts/              Bebas Neue, Barlow, Barlow Condensed woff2 (OFL), so the app renders offline
ios/                the Xcode project (committed); fastlane/ holds the CI lanes
  App/App/Info.plist          AdMob app id, ATT text, SKAdNetwork ids, portrait only
  App/App/PrivacyInfo.xcprivacy  UserDefaults (CA92.1) for the save mirror
assets/             icon-only.png (the game logo) and splash*.png: the @capacitor/assets sources
fix_spm_paths.cjs   capacitor:sync:after hook: a sync on Windows writes backslash SPM paths; this fixes them
test_shell.cjs      shell.js against mocked plugins in plain Node (133 checks, banner included)
check_game.cjs      ../index.html: scripts compile, PLAT_IDS keys, bag_ product ids, Shell contract
check_www.cjs       the built www/: injection order, offline, every referenced file present
```

## Build and test (Windows is fine; compiling iOS needs the CI runner)

Run `npm ci` in `native/` once. After any change to `index.html` or `shell.js`:

```
python native/build_www.py
node native/test_shell.cjs
node native/check_game.cjs
node native/check_www.cjs
cd native && npx cap sync ios
```

`python native/build_www.py --release` builds with the live AdMob units and refuses to build while
any id below is still a placeholder.

Icon and splash: `assets/icon-only.png` is the game's logo (the same art as `apple-touch-icon.png`),
rendered at 1024x1024 from the game's own `avatar()`: an orange radial-gradient square, "GOAT" in white
900-weight type, and the avatar with look `{skin:4,hair:1,hc:0,fh:3,face:4,head:1,arms:0,jew:1,guard:0,jer:0,trim:0,js:0,num:23}`,
age 24, size 150, via a Playwright element screenshot at deviceScaleFactor 1024/180. `splash.png` / `splash-dark.png`
(2732x2732) are that icon as a rounded tile on the game's dark background with an orange glow. After
changing either, run `npx capacitor-assets generate --ios` in `native/`.

## In-app products

Created 2026-11-06 in App Store Connect (through the API, with review screenshot, worldwide availability and a USD
base price) and imported into RevenueCat project "Build a GOAT" (in-app purchase key and App Store Connect API key
shared with The Fort/Euchre). App
Store product ids are unique across a developer account, and Euchre and The Fort already sell
`remove_ads`, `coins_*` and `fort_*`, so every Build a GOAT id is `bag_`-prefixed. The USD values in
`index.html` are only the label shown before the store answers.

| Product id | Type | Grants | Price |
|---|---|---|---|
| `bag_gems_t1` | consumable | 40 gems | $1.99 |
| `bag_gems_t2` | consumable | 110 gems | $4.99 |
| `bag_gems_t3` | consumable | 250 gems (tagged Popular) | $9.99 |
| `bag_gems_t4` | consumable | 550 gems | $19.99 |
| `bag_gems_t5` | consumable | 1,500 gems (tagged Best value) | $49.99 |
| `bag_noads` | non-consumable | removes the banner (the reward ad stays optional) | $3.99 |

For scale: a Pro career pays about 5 to 16 gems, a GOAT career 45, Hall of Fame 1.5×, and maxing
every piece of gear costs 1,700. Each pack gives about 10-14% more gems per dollar than the one
before it, and the top pack stays under 1,700 so it never buys more than the game can use. Ids are by tier
(`_t1`..`_t5`), not by amount, because a product id can never be renamed: retune the amounts in
`SHOP_PACKS` freely.
